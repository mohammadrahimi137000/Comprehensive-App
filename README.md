# برنامه جامع | Comprehensive-App

نرم‌افزار دسکتاپ Windows برای پایش خودکار پنجره‌های چارت، دریافت داده XAUUSD، ساخت کندل، تحلیل چندموتوره، پیش‌بینی پژوهشی ۱۵ دقیقه‌ای، نمایش Overlay مشروط، ژورنال و گزارش عملکرد. برنامه هیچ سفارشی به کارگزاری ارسال نمی‌کند.

## استراتژی چرخه‌ای GOLD (فعلاً فقط سیاست/تست، بدون اجرای سفارش)

- ماژول `hedge_cycle_strategy.py` منطق چرخه ۵ ثانیه‌ای را به‌صورت intent پیاده می‌کند: شروع با BUY+SELL، خروج مستقل هر موقعیت در سود خالص +۱ دلار یا زیان خالص -۰٫۵ دلار، و پس از شکل‌گیری موقعیت سودده، افزودن فقط در جهت موقعیت سودده قوی‌تر.
- سقف پیش‌فرض ۱۰ موقعیت باز برای جلوگیری از رشد نامحدود تعداد معاملات؛ در صورت رسیدن به سقف، سفارش جدیدی پیشنهاد نمی‌شود.
- ماژول به‌صورت پیش‌فرض غیرفعال است و فقط intent تولید می‌کند. هنوز به پنل Trendo متصل نیست؛ PnL خالص باید از خود بروکر خوانده شود و هر باز/بسته‌شدن باید با شناسه معامله تأیید شود. اجرای واقعی تا اعتبارسنجی فرم سفارش و کنترل‌های توقف اضطراری فعال نیست.
- تست‌ها: `tests/test_hedge_cycle_strategy.py`.

## قابلیت‌های پیاده‌سازی‌شده

- شناسایی پنجره‌های قابل مشاهده با Windows API و OpenCV؛
- شناسایی پنجره‌های Trendo در نسخه دسکتاپ و Chrome و نمایش وضعیت اتصال در داشبورد؛ این اتصال فعلاً فقط خواندنی است و هیچ کلیک یا سفارشی ارسال نمی‌کند؛ پنجره‌های minimized، پوشیده‌شده یا بعضی سطوح hardware-accelerated قابل تضمین نیستند.
- استخراج هندسه کندل‌ها و ROI؛ OCR اختیاری برای نماد، تایم‌فریم و قیمت‌های محور با Tesseract.
- استخراج OHLC تصویری تخمینی تنها پس از کالیبراسیون؛ این تخمین هرگز به کندل‌های قابل معامله/SQLite اضافه نمی‌شود.
- دریافت تیک زنده XAUUSD از BiQuote SignalR، fallback محدود REST و رد quote کهنه/بسته/نامعتبر.
- bootstrap تاریخچه کندل‌های بسته‌شده BiQuote برای M1/M5/M15/H1/H4؛ ساخت کندل‌های محلی M1/M5/M10/M15/H1/H4 از تیک‌های تازه.
- ذخیره SQLite با جداسازی منبع‌ها؛ موتور تحلیل در هر اجرا فقط یک منبع مستقل را انتخاب می‌کند و کندل‌های Spot و Broker را با هم مخلوط نمی‌کند.
- پایش مرجع Spot از XAUS و Corgano فقط وقتی quote بروکر تازه است؛ این منابع فقط برای کنترل اختلاف‌اند و جای Bid/Ask را نمی‌گیرند.
- مغزهای تکنیکال، پرایس‌اکشن، آمار نوسان و proxy نقدینگی با شواهد و وزن‌های شفاف؛ EMA و برچسب روند بین موتور اصلی و مغز تکنیکال از یک پنجره محاسباتی مشترک استفاده می‌کنند.
- ساختار سوئینگ HH/HL/LH/LL، شکست ساختار BOS، تغییر شخصیت CHoCH، sweep نقدینگی مبتنی بر OHLC، و نزدیک‌ترین زون حمایت/مقاومت با درنظرگرفتن زون‌های حاوی قیمت.
- هم‌ترازی و اختلاف مغزها به‌صورت صریح در خروجی؛ موتور آمادگی ورود فقط با OHLC بروکر، quote تازه Bid/Ask، چارت کالیبره‌شده، تأیید شکست پرایس‌اکشن و مقایسه Spot مستقل، پلن دستی می‌سازد. این خروجی سفارش خودکار نیست.
- ارزیابی خودکار پیش‌بینی‌های بالغ‌شده در برابر کندل‌های بعدی؛ نرخ اصابت هر مغز و میانگین خطای مسیر قیمت به‌صورت توصیفی گزارش می‌شود و با احتمال کالیبره‌شده اشتباه گرفته نمی‌شود.
- پیش‌بینی پایه با ترکیب مومنتوم اخیر و امتیاز جهت‌دار به‌همراه fan نوسان ATR؛ سطح اطمینان low/unvalidated است و سناریوها احتمال کالیبره‌شده محسوب نمی‌شوند.
- مدل Logistic Regression سبک با جداسازی زمانی train/holdout، گزارش Accuracy/Brier و ذخیره محلی مدل؛ فقط برای نماد/تایم‌فریم/منبع آموزشی خودش فعال می‌شود.
- فشار خرید/فروش مبتنی بر جهت تغییر mid تیک؛ این داده order book یا aggressor واقعی نیست.
- خبرهای بازار، تقویم اقتصادی بااهمیت BiQuote، RSS دلخواه و هشدار رویداد high-impact نزدیک افق پیش‌بینی.
- مسیر پیش‌بینی با فاصله‌گذاری متناسب با تایم‌فریم ورودی (M1/M5/M15 و بالاتر)، زون‌های استاتیک/داینامیک، تاریخچه تحلیل، ژورنال دستی، screenshot انتخابی و گزارش عملکرد بر حسب R.
- Overlay شفاف و mouse-through؛ به‌روزرسانی دوره‌ای و نمایش فقط در صورت شناسایی XAUUSD/M1، دو برچسب معتبر محور قیمت و فاصله‌گذاری منظم کندل‌ها.

## نصب و اجرا

Python 3.12 روی GitHub Actions آزمایش می‌شود. زمان‌بندی جلسه بازار بر اساس ساعت نیویورک و ZoneInfo است تا تغییر ساعت تابستانی/زمستانی خودکار اعمال شود. data/market_holidays.json تاریخ‌های تعطیلی کامل مرجع و رویدادهای ساعات ویژه CME/LBMA را ثبت می‌کند؛ این تقویم‌ها جایگزین تقویم بروکر OTC نیستند. فقط closed_dates به‌عنوان تعطیلی کامل اعمال می‌شود و رویدادهای partial-hours اطلاع‌رسانی‌اند. تاریخ تعطیلی اختصاصی بروکر را فقط پس از تأیید ساعات همان بروکر به closed_dates اضافه کنید. سازگاری Python 3.15 هنوز تأیید نشده است.

    git clone https://github.com/mohammadrahimi137000/Comprehensive-App.git
    cd Comprehensive-App
    py -3.12 -m venv .venv
    .\.venv\Scripts\Activate.ps1
    python -m pip install --upgrade pip
    pip install -r requirements.txt
    python main.py

### فعال‌سازی OCR

pytesseract با pip نصب می‌شود، اما خود برنامه Tesseract OCR باید جداگانه روی Windows نصب شود. در صفحه «تنظیمات» مسیر tesseract.exe را وارد کنید. اگر Tesseract نصب نباشد یا محور قیمت خوانده نشود، تشخیص پنجره همچنان کار می‌کند ولی کالیبراسیون و Overlay غیرفعال می‌ماند.

## تست و ساخت فایل اجرایی

    python -m pytest -q
    Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
    .\build_windows.ps1

فایل‌های خروجی PyInstaller در dist/ComprehensiveApp/ قرار می‌گیرند. Workflow «Windows executable» نیز از GitHub Actions قابل اجراست. Tesseract باینری باید جداگانه روی رایانه مقصد نصب شود.

## محدودیت‌های مهم و صادقانه

- OCR در همه پلتفرم‌ها، زبان‌ها، تم‌ها و زوم‌ها قابل تضمین نیست. برای جلوگیری از رسم گمراه‌کننده، در صورت کالیبراسیون نامعتبر Overlay خاموش می‌ماند.
- OHLC حاصل از تصویر فقط تخمین هندسی است. تحلیل قیمت به کندل‌های مستقل BiQuote متکی است، نه مقادیر OCR.
- وزن مغزها فعلاً وزن اولیه ثابت است؛ یادگیری وزن بر اساس عملکرد بلندمدت و کالیبراسیون آماری احتمال‌ها هنوز به ارزیابی خارج از نمونه و داده زنده بیشتر نیاز دارد.
- مدل ML فعلی baseline پژوهشی با یک holdout زمانی است؛ تضمین سود یا مزیت معاملاتی نیست.
- داده order book/L2 و aggressor واقعی در feed موجود نیست؛ liquidity و tick pressure فقط proxy هستند.
- خبرها و تقویم اقتصادی context و هشدار رویدادند، نه مدل علّی اثر خبر بر قیمت طلا.
- منابع Spot مستقل فقط اختلاف قیمت را نشان می‌دهند و جایگزین quote بروکر نمی‌شوند.
- انتخاب منبع در تحلیل، aliasهای spot و broker را به نام واقعی منبع ذخیره‌شده نگاشت می‌کند؛ منابع مستقل با هم ترکیب نمی‌شوند.
- اجرای سفارش از طریق رابط گرافیکی Trendo هنوز پیاده‌سازی یا فعال نشده است؛ مختصات کلیک یا selector حدسی استفاده نمی‌شود. برای فعال‌سازی بعدی باید فرم سفارش، نوع سفارش، کنترل حجم، SL/TP و تأیید قطعی معامله در هر دو نسخه جداگانه اعتبارسنجی شود.
- CI کد و تست‌های خودکار را بررسی می‌کند، اما اتصال واقعی SignalR، نصب Tesseract، capture چندمانیتوره، تشخیص چند چارت هم‌زمان و هم‌ترازی Overlay باید روی Windows کاربر و در زمان باز بودن بازار آزمایش شود. وضعیت ready_for_manual_review فقط پلن پیشنهادی است و هیچ سفارش خودکاری ارسال نمی‌کند.

## حریم خصوصی

پردازش تصویر روی رایانه محلی انجام می‌شود. OCR دوره‌ای از capture حافظه‌ای استفاده می‌کند و screenshot فایل فقط با اقدام کاربر برای ژورنال ذخیره می‌شود. کندل‌ها، مدل آموزش‌دیده و ژورنال در پوشه data/ محلی می‌مانند. درخواست‌های شبکه فقط برای دریافت quote، OHLC تاریخی، خبر، تقویم و مرجع Spot هستند.
