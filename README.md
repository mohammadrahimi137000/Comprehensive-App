# برنامه جامع | Comprehensive-App

نسخه پایه یک برنامه دسکتاپ ویندوزی برای پایش پنجره‌های معاملاتی و تشخیص بصری احتمالی نمودار است.

## وضعیت فعلی

- رابط دسکتاپ PySide6 با داشبورد و صفحات اولیه.
- اتصال واقعی داشبورد به موتور پایش پنجره‌ها.
- بررسی پنجره‌های قابل مشاهده و غیر Minimized ویندوز.
- تشخیص ابتدایی الگوی کندل‌های سبز/قرمز با OpenCV.
- محاسبه محدوده اشتراک پنجره با دسکتاپ مجازی؛ مناسب‌تر برای چند مانیتور و مختصات منفی.
- توقف کنترل‌شده Thread هنگام بستن برنامه.
- تست پایه برای منطق تشخیص تصویر و CI ویندوز.

## نصب و اجرا (Windows 10/11)

پیشنهاد می‌شود Python 3.11 یا 3.12 نصب باشد.

```powershell
git clone https://github.com/mohammadrahimi137000/Comprehensive-App.git
cd Comprehensive-App
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
python main.py
```

## تست

```powershell
pytest -q
```

## محدودیت‌های مهم

این نسخه هنوز **موتور تحلیل یا سیگنال معاملاتی نیست**. تشخیص فعلی یک heuristic تصویری است و ممکن است بعضی پنجره‌های رنگی را اشتباه تشخیص دهد یا نمودارهایی با رنگ‌بندی متفاوت را از دست بدهد. فعلاً موارد زیر پیاده‌سازی نشده‌اند:

- استخراج OHLC یا قیمت از تصویر
- تشخیص قطعی نماد و تایم‌فریم
- اتصال به API یا فید زنده بازار
- تحلیل تکنیکال، سناریو، پیش‌بینی، حد ضرر و حد سود
- نمایش Overlay روی پنجره اصلی نمودار

به همین دلیل برنامه هیچ توصیه یا سیگنال خریدوفروش تولید نمی‌کند. تشخیص پنجره به‌تنهایی مبنای معامله نیست.

## ساختار

- `main.py`: رابط کاربری و اتصال رویدادهای تشخیص
- `auto_chart_detector.py`: پایش پنجره‌ها و تشخیص بصری چارت
- `window_detector.py`: ابزار خط فرمان برای فهرست پنجره‌های باز
- `tests/`: تست‌های خودکار

## حریم خصوصی

تصویر پنجره‌ها فقط در حافظه محلی برای تشخیص بصری پردازش می‌شود؛ این نسخه تصویری را آپلود یا ذخیره نمی‌کند.


## موتور تحلیل OHLC (مرحله آزمایشی)

ماژول `analysis_engine.py` یک پایه تحلیلی مستقل و قابل‌آزمایش اضافه می‌کند:
- اعتبارسنجی کندل‌های OHLCV و رد داده‌های ناسازگار.
- محاسبه EMA، RSI، ATR و مومنتوم.
- استخراج پیوت‌های ساده حمایت و مقاومت.
- ساخت سناریوهای صعودی/نزولی/خنثی و ۱۵ نقطه تخمینی یک‌دقیقه‌ای.
- خروجی شامل بازه عدم‌قطعیت، سطوح مرجع و محدودیت‌های تحلیل.

**هشدار:** امتیاز سناریوها احتمالات آماری کالیبره‌شده نیست. این ماژول فقط وقتی داده کندل معتبر به آن داده شود کار می‌کند؛ هنوز فید زنده، تطبیق نماد/تایم‌فریم، استخراج OHLC از تصویر و Overlay به آن متصل نشده‌اند. از خروجی فعلی برای ورود واقعی به معامله استفاده نکنید.


## ذخیره‌سازی محلی

ماژول `market_store.py` داده‌های کندل و تاریخچه خروجی تحلیل را در SQLite نگه می‌دارد:
- کلید یکتا بر اساس منبع، نماد، تایم‌فریم و زمان کندل؛ به‌روزرسانی بدون تکثیر.
- نگهداری داده Spot و Broker در ردیف‌های جداگانه؛ جلوگیری از مخلوط‌کردن دو نوع قیمت.
- بازیابی کندل‌ها به ترتیب زمانی و ذخیره snapshot پیش‌بینی‌ها.
- دیتابیس به‌صورت محلی ساخته می‌شود و داده‌ای به سرویس بیرونی ارسال نمی‌کند.
